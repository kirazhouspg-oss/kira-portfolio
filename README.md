# Kira Zhou Portfolio Static Site

Open `index.html` directly in a browser to view the site.

## Structure

- `index.html`: home page
- `pages/`: project and reflection pages
- `assets/css/styles.css`: layout and visual styles
- `assets/js/main.js`: small shared script placeholder
- `assets/images/`: downloaded portfolio images
- `assets/manifest.json`: original Cargo media mapping

## Editing

- Edit page copy in the corresponding HTML file.
- Replace images inside `assets/images/`, then update the matching `src` path in HTML if the filename changes.
- Adjust typography, spacing, and layout in `assets/css/styles.css`.

The original Cargo site is not modified by this local copy.
